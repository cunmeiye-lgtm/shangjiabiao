# 精制PSD模板检查与维护

处理已有PSD的结构和兼容问题，保留原图案、版式及用户编辑。此技能提供检查和修复方法，不附带通用二进制修补器，不自行修改精制原厂脚本。

## 确定范围

- 从当前请求取得目录、模板选择、忽略项和允许修改的位置。只要求检查时只读并返回报告，报告或档案落盘也限于用户指定位置及授权范围；要求副本时写入指定新目录；只有明确授权原件修改时才替换原件。已有授权继续有效，无需重复确认。
- 默认递归排除任一目录组件**精确等于“旧”**的路径；“旧版说明”等不同名称不自动排除。记录纳入和排除数量。
- 先读取[结构检查](references/inspection.md)，核对每份PSD的当前版本。模板档案与版本匹配时复用；变化文件重新检查，不能沿用旧报告。
- 只修改已识别且影响本次用途的问题。未授权改变的产品像素、ppi、透明度、模特图、文案、水印及版式保持原样。嵌套对象或同名实例需查入口与联动，不直接判错。

## 检查与修复

检查结果定位到文件、替换组/图层ID、来源UUID或切片ID，说明影响与证据。重点区分：

|症状|检查方向|
|---|---|
|替换时弹出内部文档“另存为”|实际嵌入格式是否JPEG，而非仅看外层PSD后缀|
|图案小、拉伸或裁断|内部像素/ppi、有效图案留边、外层变换及剪贴/蒙版|
|同一编号要不同素材|四份PSD中该替换入口的用途与联动来源|
|整条任务缺图或失败|主图、详情、sku、白底是否配齐，分页及导出是否可用|
|导出多页或尾页异常|用户切片的面积、边界、排序与实际导出文件|

需要修复时按[修复方法与落盘保护](references/repairs.md)选择对应操作：真正转换内部PSD/PSB、修正切片、适配详情编号或补缺白底。更改目标之外的差异必须解释，不能以整份重存“看起来一样”代替核验。

先在任务自建候选中完成改动和必要的Photoshop验证，再按已授权范围落盘。已有文件版本变化、备份不一致、用户正在编辑实际写入目标、对象用途不明或候选核验失败时停止该目标，保留现场。原件有未保存编辑时不写原件、不将编辑带入副本；这不阻断从已保存文件制作未被编辑的安全独立副本。不擅自覆盖或回滚他人的变化。

## 原生验证

- 有可用Photoshop时，用本任务候选及已有测试图片检查实际智能对象编辑、保存、关闭后重开和导出。保存/关闭仅作用于本任务拥有的文档；记录并恢复此前活动文档及会话设置，不调用关闭全部文档的脚本。
- `width.as('px')`等像素换算采用**0.001px容差**，避免毫米单位的浮点误差被误判为尺寸变化。该容差不豁免真实越界、比例变化或缺页。
- Save for Web的切片设置可能使实际导出为JPEG，即使调用参数请求PNG。核验实际文件签名、名称、数量、尺寸和内容；不只按请求格式或扩展名断言成功，不为凑格式擅改模板优化设置。
- 检查产品完整、比例与联动、尺寸整图及分页顺序。需要验证自动替换时采用与实际精制一致的替换方式；只做手工“替换内容”不等于证明精制脚本可用。
- 没有原生运行条件时照实交付静态检查和未验证项。Photoshop样本通过不等于所有PSD通过，更不等于精制全量任务或商品发布成功。

## 交付

提供问题清单或修复记录：目标路径、前后SHA-256、版本信息、备份/副本位置、具体变动、证据来源、静态与原生验证范围、未验证项。用户提供或旧报告中的元数据、亲自读取/解析当前文件、原生验证分开标注；情景输入不能写为当前PSD已经验证。修复后逐份回读最终文件并重算哈希，不只核对候选或复制回执。

获准写入档案时，按实际产物更新替换用途、头图位集合、有效切片和版本，交给素材分配流程；修复副本只更新副本档案，不顺手改原件档案。不把本批编号、内部画布或某次成功页数写成所有模板的默认值。业务PSD、来源图和真实批次记录留在用户指定目录，不存入技能安装目录或发布仓库。
