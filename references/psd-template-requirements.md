# 精制套图：PSD模板制作要求

记录日期：2026-10-28。用于模板制作、检查和精制本地试套。以下“通用要求”与“本次验证参数”分开使用，不把某一款的参数套到全部模板。

## 1. 一套模板需要四份文件

同一模板目录内准备齐：

```text
主图.psd
详情.psd
sku.psd
白底.psd
```

- 文件名按上述名称保存，SKU文件使用小写`sku.psd`。
- 精制的常规任务可能先套主图、详情、白底，再单独套SKU。只提供主图时，即使主图已经成功，整条任务仍可能因缺`sku.psd`而失败。
- 表格中将详情或SKU图片位置留空，不等于软件不会调用对应PSD。未验证的软件选项不能当作跳过依据。
- 主图、详情、SKU和白底的出图页数不必相同，应按实际有效切片记录；SKU图片数也不等于SKU规格数。

## 2. 产品智能对象的内部文件格式

**用于反复替换产品图的智能对象，内部采用嵌入式PSD／PSB内容。**

- 外层文件叫`主图.psd`，不代表里面的智能对象也是PSD。必须检查智能对象实际嵌入文件格式。
- 避免把JPG直接作为需要容纳透明PNG、新图层的产品内部文档。JPG不能保留透明和多图层，脚本保存内部内容时可能触发“另存为”，打断自动替换。
- 直接将文件名后缀由`.jpg`改成`.psd`无效，必须真正以Photoshop格式保存，再替换回原智能对象。
- 优先嵌入素材，不依赖某台电脑的外部链接文件。若使用链接对象，必须另行验证所有执行电脑均能访问链接来源。
- 同样会被脚本反复编辑、增加图层的其他对象也需检查格式兼容性；不要求无关的固定水印、说明图一律改格式。

### 已有JPG内部对象的转换方法

1. 先保存外层PSD的工作副本。
2. 双击产品智能对象缩略图，打开其内部文档。
3. 使用“文件 → 存储为”，格式选Photoshop PSD；较大文档可使用PSB。
4. 保持原内部像素尺寸、分辨率及占位内容位置，保存为新的内部文件。
5. 回到外层PSD，选中原产品智能对象，右键“替换内容”，选中新保存的PSD／PSB。
6. 核对外层缩放、位置、旋转、剪贴和联动，再保存外层工作副本。
7. 再双击缩略图确认内部已是PSD／PSB，并在副本中试替一张透明产品图，确认保存无需另存提示。

**只执行内部另存，不执行第5步，不代表外层原对象已改用新格式。** 也不要通过反复“转换为智能对象”制造未经核验的嵌套层级。Photoshop“替换内容”的说明见[Adobe文档](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/smart-objects/replace-the-contents-of-a-smart-object.html)。

## 3. 画布、分辨率与有效图案区域

制作时分别记录下面四项，不能只看“都是4000像素”：

| 项目 | 需要记录的内容 |
|---|---|
| 外层PSD画布 | 主图、详情等整份文件的宽高 |
| 内部来源画布 | 每个可替换智能对象的真实像素宽高和ppi |
| 图案有效区域 | 图案在整张素材中占多大、透明留边有多少、位于哪里 |
| 外层展示区域 | 对象的变换框、剪贴矩形、蒙版和切片边界 |

- 同像素尺寸不等于相同显示大小。ppi差异可能影响Photoshop的置入尺寸；大量透明留边也会使有效图案显小。实际结果还取决于脚本采用的适配方式。
- 新模板按本类产品建立明确的内部像素尺寸、ppi和留边约定，同一用途的来源在四份PSD中保持兼容。**不统一强制全部模板使用4000×4000或72ppi。**
- 保持产品等比。需要完整展示时，图案应同时落在内部画布和外层可见区域内；不能只放大内部画布，却忽略外层矩形仍在裁切。
- 长宽比例、ppi或透明留边不同的素材，先以原文件试套。是否需要标准化或调整模板，要根据实测决定，不能默默修改原素材参数。
- 内部对象名称中的“3x10.5”等文字不能代替实际像素、ppi或实物尺寸检查。

## 4. 替换组、编号和素材文件名

- 建议将直接替换入口放在顶层，采用清晰编号，如`图案1`、`图案2`。实际名称以精制已验证的识别方式为准。
- 名称不能带首尾空格、错号或含义不明的同名组。不要出现应为“图案9”却写成“图案19”的情况。
- 一套四份PSD中，**相同编号必须表示同一种素材用途和同一份输入**。
- 产品、效果、尺寸、固定显色前后分别安排编号；不能让主图中的“图案3”是效果图、详情中的“图案3”却是尺寸图。
- 素材主文件名与实际入口一致，例如`图案1.png`。保留真实扩展名，不能将JPEG仅改名成PNG。
- 每个替换入口保留明确的目标智能对象；移除工作副本中的无用旧对象或另作归档。隐藏旧对象也可能干扰脚本找目标，不能仅凭“看不见”认为无影响。
- 嵌套结构必须检查实际替换入口及脚本行为，不能只因存在嵌套就认定可用或不可用。

## 5. 联动、独立来源及固定内容

- 同款产品在白底、SKU等页面重复展示，可使用同来源联动副本；替换一次应更新全部应联动的位置。
- 不同款式或需要分别分配照片的效果位，应使用独立来源，不能误共享同一内容。
- “出现多个实例”不一定是错误；应检查它们是否属于同一UID联动，还是组内存在多个不同来源。
- 模板编号提示文字在成品中隐藏；固定文案、水印、使用说明和质检等内容逐项确认。它们不会因替换产品自动变得适合新商品。
- 尺寸位应替换完整尺寸图，包括标尺、数字及单位；保留整张，不只替换其中的产品图案。

## 6. 分页与头图

- 以有效用户切片及实际精制导出为依据，参考线不能代替切片。
- 方图模板可采用统一边长W、外层高度为W×页数；1000×1000是现有常用页尺寸，不是所有模板的唯一标准。
- 切片完整覆盖预期内容，避免重复、遗漏、重叠、零高度边界切片及有内容的尾页被丢掉。
- 记录每个切片实际用途，核对主图、详情、SKU和白底导出数量与排序。
- 头图按实际指定切片判断，不按图案编号猜。男5已有案例按第二个主图切片；其他模板分别记录。
- 头图中有多个独立效果位时，记录完整位置集合。后续素材分配必须按已确认的头图去重口径覆盖这些位置，不能只检查其中一个就声称整张头图无重复。

## 7. 配套表格和素材

- 每个会被替换的入口均提供对应文件，不依赖缺图时保留的内嵌占位内容。
- 表格中的主图、详情、SKU位置来自实际导出。多位置按本项目已确认的**中文逗号“，”**分隔，例如`1，2，3，4，5`，不使用顿号“、”。
- 首次本地测试使用**上架模式3：只套图、不上架**，状态0。保存草稿是独立字段，按本批设置，不与模式或状态混淆。
- 素材、PSD、成品目录分别设置；填写可访问的UNC路径，不直接用执行电脑的映射盘符作为跨电脑路径。
- 测试图片可以保留模板效果照用于验证替换，但正式上架前必须核对效果照、产品图、尺寸图均对应实际商品。

## 8. 验收与留档

交付前完成一轮真实精制软件测试：

1. 四份PSD齐全，替换入口和全部素材对应。
2. 使用透明产品图验证内部保存，不能出现需要人工“另存为”才能继续。
3. 肉眼检查图案完整、尺寸合理、比例正常、没有占位图或可见编号文字；检查联动与各款独立性。
4. 检查四类导出文件数量、顺序和表格位置。
5. 以软件实际任务成功和成品核验为准。脚本返回“OK”或仅生成了PNG，不能独自证明每个对象已正确替换。

修改前保留原件；默认在工作副本制作和验证，不改用户正在编辑的文档、不擅自改精制原厂脚本。运行会关闭全部Photoshop文档的原厂脚本前，先由用户处理未保存编辑。

模板档案绑定文件版本，记录路径、大小、修改时间、SHA-256、替换用途、内部画布/ppi、联动、头图和有效分页。PSD内容变化后重新检查相应部分，不能沿用旧版结论。

## 9. 本次C模板与S59成功案例

这是案例参数，不能直接推广到所有模板：

| 项目 | 本次记录 |
|---|---|
| 模板系列 | C-4x11.5，第10套 |
| 产品输入 | S59原始PNG，4000×4000、约300ppi；实际非透明区域1146×422 |
| 产品内部画布 | 4000×4000、72ppi |
| 原问题 | 内嵌`3x10.5.jpg`，替换保存时出现另存提示 |
| 处理 | 使用真正的`3x10.5.psd`替换产品内部来源，保持内画布、ppi和外层变换 |
| 文件配套 | 补齐主图、详情、sku、白底；不是只准备一份主图 |
| 实际有效页数 | 主图5、详情5、SKU2、白底2 |
| 测试表 | 模式3、状态0；主图和详情位置1，2，3，4，5；单条测试SKU图位置1 |
| 成功依据 | 2026-10-28用户反馈“成功了”；此前另存问题及缺文件问题分别排除 |

本次仍有明确的测试限制：详情“图案3”原为A2004尺寸图，与其他PSD的效果位冲突，本轮使用同名效果图验证流程；效果照也不代表已经更换为S59实拍。**流程跑通，不等于已完成S59正式商品图制作。** 制作正式通用模板时仍需统一编号并提供正确尺寸图。
